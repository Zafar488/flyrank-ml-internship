I built a reproducible content-review prioritisation workflow from 9.84 million anonymised daily search-performance records, using separated feature and outcome windows and a grouped-client holdout with zero client overlap. The selected Logistic Regression model measured Precision@50 of 0.640 against 0.520 for a transparent baseline, while an explicit leakage test demonstrated how future-derived fields can create invalid near-perfect evaluation. I converted the validated score into a public-safe, reason-coded human-review queue and deployed the paper, figures, receipts, model, and reproducible notebook through GitHub Pages.
